## 目前狀態

專案已依使用者要求暫停推進。本文件整理既有成果，不代表新增測試或部署。

目前是**合成 PDF 雲端解析原型**，不是可正式使用的郵件附件處理服務。已具備 PDF 解析、部分加密格式相容性、中文測試與本機效能優化成果；「從手機指定郵件、取得加密附件、輸入密碼後完成解析」的完整流程尚未完成。

未驗證目前優化版能穩定符合 Cloudflare Workers Free 的每請求 CPU 限制，亦未以真實文件或真實密碼驗收。

## 最新實際阻礙：HTTP 403

最新精簡 smoke 在 Cloudflare 測試版本準備後，嘗試呼叫測試 Worker；呼叫受到 MCP 執行環境的外連目的地限制，返回 403，未取得 CF-Ray。

這是**測試呼叫通道限制**，不是已證明的解析器缺陷，也不是 CPU 耗盡證據。無法證明該請求抵達 Worker，故沒有可採用的最新解析結果或每請求 CPU 數據。缺少數據不能寫成 CPU 為 0。

既有執行紀錄顯示，測試後已恢復原本關閉的基準版本，公開入口、預覽及記錄功能關閉，作用中的綁定不含測試密鑰。歷史未作用版本可能仍有已過期的測試設定，不應宣稱歷史設定已全部刪除。

## GitHub 移交前仍需整理

現有程式分散於多個實驗目錄，建置腳本使用其他目錄的依賴，因此**目前不是獨立、乾淨且可直接重建的 repository**。

只複製 Worker 目錄會缺少：

- 官方 PDF.js 主模組。
- 已修改的 PDF.js worker 模組及其來源／修改說明。
- 固定 CMap 資源。
- Canvas geometry 相容層。
- esbuild 等建置依賴、版本鎖定及相關授權文件。

整理時應保留原始成果快照，再將相依檔案納入明確的目錄與套件管理。任何路徑、套件或建置設定調整後，都必須重新驗證；不能直接沿用整理前的測試通過聲明。

- `README.md`：專案用途、合成資料限定、安裝／建置／測試方法與目前限制。
- `docs/status.md`：區分本機已驗證、雲端已驗證、失敗與未知。
- `docs/benchmarks.md`：保存測試環境、樣本、量測單位及本機／雲端差異。
- `archive/`：僅放確實有保留價值且已清理的歷史實驗，不作為預設執行路徑。
- `.env.example`：只放占位值；不附任何實際帳號、憑證或測試密鑰。

## 不應納入發布內容

- 真實郵件、真實 PDF、真實密碼、存取憑證與環境變數檔。
- 已產生的即時執行請求、授權紀錄、短效密鑰或未清理的原始服務回應。
- 私人帳號／部署識別資訊、內部協作紀錄與個人工作路徑。
- 整個工作區、未審核備份壓縮檔、套件快取或 `node_modules`。

應以明確允許清單組成移交內容，並在 commit 前檢查敏感資料及第三方授權。即使 repository 設為 private，也不應提交憑證。

## 恢復推進時的建議順序

1. 完成可重建的 repository 整理，固定依賴與合成測試資料。
2. 重新跑本機功能測試，建立單一可信的測試報告。
3. 使用正式支援、可直達 Worker 的測試通道，先完成一份合成加密 PDF 的真實雲端解析。
4. 再量測雲端 CPU、延遲及資源限制，據此決定是否適合免費方案。
5. 核心功能與雲端可行性確認後，再補齊正式使用所需的權限、憑證管理及端到端流程。

測試期間仍需保留基本隔離與存取保護，不以真實敏感文件取代合成測試。此清單是後續計畫，不是已開始執行的工作。
